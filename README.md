# Proyecto de Teoría de Grafos y Coordenadas GPS en Python

## Descripción del proyecto

Este proyecto implementa conceptos de teoría de grafos utilizando Python, aplicados a la representación de ubicaciones geográficas mediante coordenadas GPS.

El objetivo es representar puntos geográficos como vértices y las conexiones entre ellos como aristas, permitiendo analizar relaciones y recorridos entre diferentes ubicaciones.

## Tecnologías utilizadas

- Python
- Git
- GitHub
- Visual Studio Code

## Requisitos previos

- Python 3 instalado.
- Git instalado.
- Visual Studio Code.

## Instalación y ejecución

### 1. Clonar el repositorio

```bash
git clone https://github.com/anapai/Proyecto-de-Teor-a-de-Grafos-y-Coordenadas-GPS-en-Python.git
```

### 2. Entrar a la carpeta del proyecto

```bash
cd Proyecto-de-Teor-a-de-Grafos-y-Coordenadas-GPS-en-Python
```

### 3. Crear un entorno virtual

```bash
python -m venv env
```

### 4. Activar el entorno virtual

En Windows PowerShell:

```powershell
.\env\Scripts\Activate.ps1
```

En CMD:

```cmd
env\Scripts\activate
```

### 5. Instalar las dependencias

```bash
pip install -r requerimientos.txt
```

### 6. Ejecutar el proyecto

```bash
python optimizacionDistanciaConGrafos.py
```
